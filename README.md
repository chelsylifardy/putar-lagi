# Putar Lagi

Rekam suaramu ke kaset 3D, tarik pitanya sampai kusut, lalu gulung kembali dengan pensil.

    npm install
    npm run dev      # buka http://localhost:5173 (mikrofon butuh localhost/https)
    npm run build    # hasil di dist/

- `src/App.jsx` — layout halaman
- `src/components/Overlay.jsx` — tombol, status, dialog
- `src/engine.jsx` — adegan Three.js, simulasi pita, audio
- `public/logo.png` — logo
